# TrustUsConsult · Huset

Web app for TrustUsConsult: public site, specialist directory and portal. Next.js on Vercel, Postgres/Auth/Storage on Supabase.

## Run it

```bash
pnpm install
cp .env.example .env.local   # fill in the Supabase keys
pnpm dev
```
